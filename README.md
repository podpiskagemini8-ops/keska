# Бот для розыгрышей в Telegram

Бот: [@randomgoodgift_bot](https://t.me/randomgoodgift_bot).

## Пользование

1. Откройте бота и нажмите **Start** или отправьте `/start`.
2. Добавьте его администратором канала с правом **Публикация сообщений**.
3. Нажмите **Создать розыгрыш**. Перешлите сообщение из канала либо отправьте его `@username` или ссылку.
4. Задайте пост, число победителей, призы и способ завершения. Проверьте предпросмотр.
5. Нажмите **Опубликовать**, затем подтвердите публикацию. Кнопка под постом откроет участие через бота.

Настройки фиксируются после публикации. Создатель может подвести итоги вручную или отменить активный розыгрыш через **Мои розыгрыши**. Кнопки чужого розыгрыша не дают доступа к управлению; для публикации и ручного завершения проверяются права администратора канала.

## Функции

- Русское меню: создание, мои розыгрыши, профиль, отмена ввода.
- Черновики и предпросмотр; отдельное название розыгрыша.
- Текст, фото, видео, GIF или документ; сохранение форматирования исходного сообщения. Для картинки без подписи бот создаёт текст по образцу: число призов и победителей, «П Р И З Ы :», список призов по местам, условия подписки, приглашение поставить реакцию, время или число участников для итогов и «Нажать кнопку участвовать». Через **Текст поста** можно задать свою подпись — настроенные призы добавляются ниже компактным списком с диапазонами одинаковых призов. Альбомы: используется один присланный файл, а не весь альбом.
- 1–100 победителей без повторов. У администратора с ID `8259479085` верхний лимит числа победителей снят: через **Своё число** можно задать любое положительное целое число. При нехватке участников фактическое число победителей равно числу прошедших условия. Один приз каждому или призы по отдельным местам и диапазонам. Для более 10 000 отдельных мест используйте **Один приз на всех**.
- Итоги по дате и времени (**МСК**), по числу зарегистрированных участников или вручную.

Для времени можно прислать `ДД.ММ.ГГГГ ЧЧ:ММ`, `завтра 18:00`, `через 1 час` или `18:00` (сегодня по Москве). Есть быстрые кнопки **Через 1 час** и **Через 24 часа**. При публикации без даты бот сразу открывает ввод с примером; сообщение `завтра` вызывает вопрос о часах и минутах. После сохранения времени публикацию нужно подтвердить отдельно.
- Обязательные подписки: до 10 каналов. Бот проверяет их при вступлении и повторно перед жеребьёвкой.
- Бонус за приглашённых друзей: персональная ссылка, фиксированный процент за друга, максимум +300%. При итогах учитываются друзья, которые сами прошли условия. Вес участника: `100 + min(300, подходящие друзья × процент бонуса)`.
- До 8 дополнительных ссылок; текст и цвет кнопки участия; необязательные ID премиум-эмодзи.
- **Призы → Эмодзи для мест**: назначение премиум-эмодзи по ID одному месту или диапазону. Формат: `1: ID` или `4-5: ID`, несколько назначений можно отправить разными строками. ID проверяется через Telegram. Для возврата обычного эмодзи на конкретные места — `4-5: -`, для полного сброса есть кнопка. Последнее назначение имеет приоритет. Диапазон одинаковых призов разделяется, если его частям назначены разные эмодзи. В подписи между призами есть пустая строка, номера мест выделены жирным.
- Контакт для выдачи призов, обязательный @username, личные уведомления только победителям. Список победителей в канал или отдельным сообщением организатору не отправляется.
- Промо: число участников на кнопке, закрепление поста, одно напоминание в канал перед итогами по времени.
- После завершения кнопка под постом меняется на **Розыгрыш завершён**. По ней отображается только статус завершения, без имён победителей. В уведомлении победителю указаны место, приз и контакт организатора.

### Ограничения Telegram

**Реакции в каналах анонимные:** Bot API не даёт сопоставить их с участниками. Кнопка бонуса за реакцию объясняет ограничение; этот бонус не начисляется. [Документация](https://core.telegram.org/bots/api#messagereactioncountupdated).

Цвета кнопок поддерживаются Bot API. Премиум-эмодзи в сообщениях канала доступны ботам, отвечающим требованиям Telegram; обычного токена недостаточно. Если Telegram отклонит публикацию с таким ID, уберите ID в настройках кнопки. [Документация](https://core.telegram.org/bots/api#inlinekeyboardbutton).

Для проверки подписок бот должен быть администратором каждого требуемого канала. Эта версия дополнительно требует право публикации. Закрепление в канале требует права редактирования сообщений.

Проверка @username не гарантирует защиту от нескольких аккаунтов одного человека. Бот не может проверить возраст Telegram-аккаунта или установить личность владельца.

При итогах по количеству цель определяется числом зарегистрированных участников. Если к итогам часть отписалась, подходящих участников может быть меньше цели. При нехватке подходящих участников победителей будет меньше числа мест; одно лицо не занимает два места. Если никто не прошёл условия, победителей нет.

Сбой проверки подписок откладывает жеребьёвку; бот не исключает участника только из-за сетевой ошибки. При автоматических итогах организатору приходит уведомление, а попытка повторяется.

Уведомления отправляются очередью с учётом ограничения частоты. Заблокировавшим бота сообщения не доставляются; количество неудачных доставок видно в профиле. При прерывании соединения после фактической отправки Telegram иногда возможна повторная доставка уведомления. Победители сохраняются до отправки уведомлений и не выбираются повторно.

## Запуск на компьютере

### Закрытая админ-панель

Команда `/admin` работает в личных сообщениях только для Telegram ID `8259479085`. Она не добавлена в список команд, обычное меню или справку. Для остальных пользователей команда и подделанные кнопки панели игнорируются без ответа.

В панели доступны реальные показатели:

- Пользователи, которые обращались к боту, и база с ID, именами и username.
- Уникальные участники и суммарное число заявок; отдельные участники каждого розыгрыша.
- CSV-выгрузки пользователей и участников.
- Подготовка рекламной рассылки, предпросмотр, подтверждение отправки, отмена оставшейся очереди и статистика доставки.

Бот не видит, кто сейчас онлайн. Рекламная подписка выключена по умолчанию; пользователь может включить её в **Профиле**. Рассылка отправляется только подписавшимся. Подписка повторно проверяется перед отправкой; в каждом рекламном сообщении есть кнопка отписки, также работает `/unsubscribe`.

База прежних пользователей сохраняется при обновлении. Рекламная рассылка не запускается автоматически: сначала администратор готовит пост и подтверждает отправку кнопкой. При потере ответа Telegram рекламное сообщение не отправляется автоматически повторно; такой результат отображается отдельно как неопределённый.

Счётчик на кнопке показывает реальные регистрации; повторная заявка не увеличивает его. Результаты остаются случайными, с настроенными бонусами и без повторяющихся мест.

### Запуск и остановка

Нужен Python 3.12 или новее. Дополнительных библиотек нет.

Конфигурация — `.env`, образец — `.env.example`:

```dotenv
BOT_TOKEN=токен_из_BotFather
BOT_DB=data/bot.sqlite3
```

Токен не хранится в исходном коде и не выводится в журналы. `.env`, база и журналы исключены из Git. Не публикуйте `.env`. Если токен был раскрыт, замените его через BotFather, обновите `.env` и перезапустите бот.

Запуск в терминале:

```powershell
python run.py
```

Запуск в фоне без окна:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-bot.ps1
```

Остановка фонового процесса:

```powershell
powershell -ExecutionPolicy Bypass -File .\stop-bot.ps1
```

Автозапуск при входе текущего пользователя в Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install-autostart.ps1
```

Скрипт создаёт `TelegramGiveawayBot.vbs` в папке автозагрузки текущего пользователя. Он запускает только `run.py` из этой папки. Отключение — `remove-autostart.ps1`. Если папку проекта переместили, повторно установите автозапуск.

Для работы компьютер должен быть включён, пользователь должен войти в Windows, а интернет должен быть доступен. Во сне бот не работает. После запуска бот обработает просроченные автоматические итоги. Запуск при входе не заменяет сервер или службу Windows.

Повторный запуск из той же папки блокируется, чтобы два процесса не проводили один розыгрыш параллельно. Если этот токен уже используется другим процессом, Telegram вернёт конфликт; устраните второй запуск.

Проверка связи и настройка описания бота:

```powershell
python run.py --check
python run.py --setup
```

Рабочие данные: `data/bot.sqlite3`; журнал: `logs/bot.log`. Для резервной копии остановите бот и скопируйте папку `data`. Потеря базы означает потерю участников и управления опубликованными розыгрышами.

Если ответ Telegram при публикации потерялся, бот сохраняет статус проверки публикации. Откройте такой розыгрыш в списке и перешлите опубликованный пост для восстановления управления. Если поста действительно нет, верните черновик и повторите публикацию. Это предотвращает автоматическую повторную отправку потенциального дубля.

## Выбор победителей

Бот выбирает победителей случайно с учётом настроенных бонусов, без повторов. Итоги и очередь уведомлений сохраняются одной транзакцией; перезапуск не выбирает победителей заново. Технические данные жеребьёвки сохраняются внутри базы и не добавляются к тексту поста или подтверждению участия.

## Проверка проекта

```powershell
python -m unittest discover -s tests -v
```

Тесты используют имитацию Telegram и не публикуют посты в настоящие каналы. Проверяют доступ владельца, подписки, повторные заявки, бонусы, выбор победителей, сохранение данных, восстановление публикации и очередь уведомлений.

Повторный запуск: «Мои розыгрыши» → завершённый или отменённый розыгрыш → «🔁 Запустить повторно». Настройки копируются в новый черновик, включая пост, призы и премиум-эмодзи. Участники, результаты и сообщения предыдущего запуска остаются в старом розыгрыше. Для завершения по времени задайте новую дату, затем проверьте предпросмотр и опубликуйте. Старые настройки сохраняются в базе после перезапуска компьютера.
